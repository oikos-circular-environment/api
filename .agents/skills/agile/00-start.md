# Agile Workflow — Início (Levantamento de Requisitos)

## Filosofia de Colaboração

O objetivo deste workflow é alinhamento — chegar a um conjunto de decisões tomadas em conjunto, não entregáveis a serem produzidos rapidamente.

Sistema de valores:
- Perguntas são investimentos em correção, não sobrecarga
- Surfacear suposições cedo é barato; consertar trabalho errado é caro
- Acertar na primeira vez é mais rápido do que iterar sobre trabalho errado
- Múltiplas rodadas de clarificação são normais e encorajadas

Antes de avançar para a próxima fase:
1. Surface suas suposições-chave com honestidade genuína
2. Continue fazendo perguntas até estar genuinamente confiante
3. Só avance quando você e o usuário tiverem entendimento compartilhado

## Clarificação Multi-Rodada

Se a incerteza persistir após as perguntas iniciais, apresente mais perguntas de entrevista.

- Múltiplas rodadas de clarificação são normais e encorajadas
- Não se sinta pressionado a avançar após uma rodada de respostas
- O objetivo é entendimento compartilhado, não velocidade

## Processamento da Solicitação

1. Entenda a solicitação do usuário e use perguntas de entrevista para resolver requisitos ambíguos, preencher detalhes faltantes, etc. Múltiplas rodadas de clarificação são esperadas. Alcance alinhamento e entendimento compartilhado com o usuário.

2. Uma vez clarificado, apresente um resumo muito conciso dos requisitos acordados. Em seguida, sugira prosseguir com as próximas fases do workflow.

   Nota: Esta fase é SOMENTE para levantamento de requisitos. É uma fase somente leitura — não envolve criação de nenhum artefato.

## Critérios de Aceitação

- A solicitação do usuário é transformada em requisitos precisos via entrevista estruturada — sem suposições.
- O usuário está satisfeito com os requisitos.

## Princípios

- Intenção do usuário em primeiro lugar: o workflow guia, mas o usuário dirige.
